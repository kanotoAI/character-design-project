## iPhoneからの登録手順
1. GitHubでこのフォルダを開く。
2. **Add file → Upload files** を選ぶ（スマホ画面で操作しづらい場合はSafariの「デスクトップ用Webサイトを表示」を使う）。
3. 画像を選び、ファイル名を `AYA_ROUND_02_source_candidate.jpeg` にする。**画像の再保存・スクリーンショット化・変換はしない**。
4. コミット後、ChatGPTへ「登録したよ」と伝える。こちらで実在・サイズ・Git blob SHA・SHA-256を検証する。

## 検証と登録の条件
- 画像の実体と台帳 `../05_history/image_library.md` を混同しない。
- GitHubのSHA-1 blob IDと元画像のSHA-256は別物。サイズだけで一致と判断しない。
- 正式資料への昇格はユーザーの明示的承認が必要。
- 編集は原本を上書きせず別名で保存。比較画像は生成AIに描かせず実画像を非生成的に並べる。
- `_pipeline_probe/` はバイナリ経路検証専用で、作業基準画像ではない。

## 現状の制約
GitHubコネクタでは小さなバイナリをBase64でコミットし、Base64で再取得する実験は成功した。ただし**会話添付の原本約436KBをローカルからGitHubコネクタへ渡す直接的なファイル転送経路は未確立**。原本のGitHub登録は現時点では手動アップロードが必要。
