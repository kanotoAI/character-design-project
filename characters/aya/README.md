# あや — キャラクターデザイン資産

ここは**あやの外見と正式画像資料**を管理する場所。会話するあやの人格・呼称・応答スタイルはChatGPTプロジェクト側の人格設定を正とし、ここで二重管理しない。

## 現行の参照先
- [外見設定](01_settings/appearance.md)
- [正式参照と画像の状態（manifest）](05_history/manifest.md)
- [作業ToDo・実験履歴](05_history/todo.md)
- [画像生成ルールv3.2.4の採用記録](05_history/261116_image_generation_rules_v3.2.4_adoption.md)

正式に承認されたキャラクターデザイン資料・表情資料の実ファイルと状態は `05_history/manifest.md` を基準に確認する。README中でファイル名・状態・SHAを重複管理しない。

## 作業の区分
- 正式資料の修正・新規MASTERへの採用→本リポジトリの制作ルール、外見正本、manifestを確認。
- ChatGPTであやを題材にして再現性などを**技術実験**する→[AI-Image-Generation-Notes](https://github.com/kanotoAI/AI-Image-Generation-Notes) の実験ルールと正式資料の必要部分を参照。実験成功と正式採用は別。
- ANIMA/ComfyUIのキャラクター固定は、学習側の**将来の保留課題**。ChatGPT生成の当面の目標に読み替えない。

## 既存記録の扱い
古い「未配置」「未確定」の案内は現在の状態ではない。移管履歴は `migration/` と `05_history/` を参照。旧TRIALの見た目の好評価を正式デザイン採用に読み替えない。玲奈の資料と混用しない。
