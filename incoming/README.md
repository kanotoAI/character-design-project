# incoming — 一時受け入れ場所

ここは画像・制作成果物の**受け入れ専用**。ここに置いただけでは正式資料・承認済み資料になりません。

- 初期状態は `WORKING` または `TRIAL`。承認済みの意味を持つファイル名・状態を勝手に付与しない。
- 原本PNGは変換・縮小・再圧縮せず保存し、元ファイルとSHA-256を照合する。
- ユーザーによる明示的な採用承認後、対象キャラクターの適切なディレクトリに配置し、`manifest.md` を更新する。
- テストデータはテストブランチで管理し、正式資料と混在させない。
- 大きなPNGの直接転送は未検証・未解決。小さいPNGでの試験成功は原本転送の成功を意味しない。
- 正式な資料管理は `rules/current_rules.md` および各キャラクターの現行正本に従う。
