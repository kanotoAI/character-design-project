# 線画化の試行 記録

## 目的
ハイライト簡略化の行き詰まりを受け、ユーザーが新方針を提案（2026-11-21）：S3をベースに線画だけを作り、改めてカラーパレットで調整して塗り直す。まずは線画だけを作る。

## 試行01（2026-11-21、生成）
- 参照：pattern_hl_s3.png を実入力し、「色・陰影・グラデーション・ハイライトを無くし、白背景に黒線のみ、構図と線は元のまま、塗りの境界は線にしない」で生成。
- 成果物：line_from_s3_01.png（PNG 1600×1600、1,239,924 bytes、SHA-256 aee38493b55325c2…）。TRIAL。
- 結果：線画としてはきれいで、塗りの境界は線になっていない。ただしS3の忠実な線画にはなっていない：
  - 構図が変わった（S3は顔アップ寄りだったが、首・タートルネック・肩まで入ったバストアップになった）。
  - 目元が変わった（瞳が小さな黒点になり、目の印象が別人寄り）。
  - 髪の輪郭が少し大きくなり、両サイドの毛流れも変わった。
- 採否：ユーザーは「設定の模索中だから完全に一緒でなくても大丈夫」とし、作り直しを指示（試行02へ）。

## 試行02（2026-11-21、生成・作り直し）
- ユーザーの条件：試行01をベースに元（S3）に寄せる／タートルネックなし／肩のラインが見えるよう服も下着もなし／肩より下は描かない／性的な表現はなし（設定画としての線画）。
- 入力：試行01の線画＋S3を参照に生成。
- 成果物：line_from_s3_02.png（PNG 1600×1600、1,127,508 bytes、SHA-256 d4bde64cac555336…）。TRIAL。
- 結果：タートルネックと服は無くなり、首から肩のラインが見えるバストアップで、構図は肩で終わっている。目は大きな虹彩の輪郭＋輪状のハイライト位置まで描かれ、試行01より元に近い。髪はS3のボブに近いが、両サイドはやや長め・ふんわりめ。顔立ちは概ね近い。
- 採否：ユーザーが「02がかなりいい感じ」と承認（2026-11-21）。この線画を土台に塗り工程へ進むことが決まった。

## 塗り試行01（2026-11-21、画素処理・生成不使用）
- 方式：線画02の線で囲まれた領域ごとに、位置合わせしたS3の色をサンプルして「元の絵では何の部分か」を判定し、実測パレットの色で平らに塗り分けた。位置合わせは比較シートの切り出し量から求めた対応で実施し、重ね合わせで目と髪が線の内側に収まることを確認済み。
- 色の割り当て：髪ベース #C7544E（元の明るい面・帯にあたる領域も全てベースに統一＝ハイライトなし）／髪の影 #A93F3A（元の影にあたる内側・下層の領域）／瞳 #BB3737・瞳孔 #7C1E21／肌 #FFE6DC／背景 白。服にあたる位置（首・肩）は肌色にした。線は温かみのある焦げ茶で上に重ねた。
- 成果物：colored_line02_01.png（618,816 bytes、SHA-256 afc25c037106712b…）。TRIAL。
- 観察：帯のない平らな髪＋影1色のツートーンで、狙いの「単色塗り寄り」が線画ベースで実現できた。瞳のハイライト円は赤のまま（白くする余地あり）。チークはなし（顔が1領域のため）。線画由来の薄い下書き線が輪郭の外に少し残っている。
- 採否・調整：ユーザーが「塗分けが甘すぎるかも。配色バランス調整ならこれくらいで良いのか」と相談。

## 塗り試行03（v3、2026-11-21、誤判定の修正）
- ユーザーの指摘で判明：「塗分けが甘い」は陰影の薄さではなく、部位の誤判定のことだった。①右耳が髪色で塗られている（耳の内側の小領域が hair_shadow 判定、耳本体も cheek 判定で色がずれていた）②アイライン（目尻のまつ毛の塊）が暗い赤で、黒ベタにしたい。
- 修正（上書きルール追加）：耳ゾーン（右 x1155–1255,y755–975／左 x350–425,y790–975）内の hair_*・cheek 領域（幅95以下）を肌 #FFE6DC に。eye_dark 領域のうち瞳孔（虹彩中心から30px以内）を除く全てを黒ベタ #231418 に。
- 成果物：colored_line02_03.png（640,678 bytes、SHA-256 3922f6ff0aed3330…）。TRIAL。拡大確認済み：compare_v3_rear.png／compare_v3_lear.png／compare_color_v2v3.png。両耳とも肌色になり、両目のアイラインが黒ベタになった。
- 教訓：位置合わせサンプリング方式は、元絵と線画で位置がずれる部位（耳など）で誤判定が出る。耳・アイラインのように意味が明確な部位はルールで上書きするのが確実。
