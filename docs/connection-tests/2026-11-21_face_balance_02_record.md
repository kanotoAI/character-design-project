## 評価（アシスタントの観察）

- M1：口が横に少し広がり、笑いの弧もやや大きくなる。変化は分かるが控えめ。
- M2：「下げる」は目の P2 と同様、生成では位置がほぼ動かなかった。確実に下げるなら画素移動（非生成）が向く。
- M3：口角が少し上がり、M1 と同じくらい幅も出ている。3種の中では表情の変化として一番分かりやすい。
- 共通：口は小さいパーツなので、どのパターンも変化は目元ほど大きくない。
