# 顔バランス試行03記録（下瞼ライン3種・土台はP1GM1）

実施：2026-11-20（ユーザーが「下瞼のラインだけ調整したい」と希望。方向を言葉で決めるのが分かりづらいため、目・口元のときと同じ方法で3パターンを先に作って見て選ぶ形で実施）
土台：顔バランス試行02の P1GM1（pattern_p1g_m1.png、現在の作業版・TRIAL）

## 方法

- P1GM1 から顔中央クロップ（x240–1000, y280–1040、760×760、crop_face_from_p1gm1.png、SHA-256 117466ae…1ac9）を生成入力し、下瞼ラインだけの変更を指示したパッチを3種生成。
- 合成マスクは下瞼専用で、両目の瞳の下を通るライン周辺の狭い帯2か所のみ（クロップ座標で角丸矩形 (110,360)–(340,445) と (460,340)–(700,430)、ぼかし8px ＝ 原本座標で目の下の帯）。目の上部・瞳・鼻・口・頬・髪は P1GM1 の画素そのまま。
- 検証：3種とも P1GM1 との変更画素は約4.9〜5.3万 px で全てマスク内（変更範囲の実測 bbox は x331–957, y601–745）。クロップ外の変更0、マスク値0の場所の変更0。

## パターン

| | 内容 | 成果物 |
|---|---|---|
| L1 下瞼ラインを濃く／はっきり | ラインがはっきり濃く、目の下の輪郭がくっきりする | pattern_l1.png（SHA-256 179a4668…） |
| L2 下瞼ラインを薄く／ほぼ消す | ラインがさらに薄く柔らかくなり、目元がすっきりする | pattern_l2.png（SHA-256 bcf3516a…） |
| L3 カーブを丸く・少し下げる | 弧が少し丸く、ラインがほんの少し下に来る。位置の移動量は控えめ | pattern_l3.png（SHA-256 b092a2cd…） |

## 評価（アシスタントの観察）

- L1：変化が一番分かりやすい。下瞼のラインが両目とも濃くはっきり出て、目の輪郭が引き締まる。
- L2：P1GM1 よりさらにラインが薄くなり、目元が柔らかい印象になる。変化は控えめ。
- L3：カーブが少し丸くなった印象はあるが、「下げる」の位置移動は目 P2・口 M2 と同じく生成では控えめで、ほんの少しの変化に留まる。確実に下げるなら後から画素移動（非生成）の方式が向く。
- 共通：下瞼ラインは細いパーツなので、どのパターンも全体の印象への影響は小さい。拡大比較で見ると違いが分かりやすい。
- 比較シート：compare_lower_lid_face.png（顔全体）、compare_lower_lid_zoom.png（目元拡大）。実画像の非生成的配置。

## ラウンド2（2026-11-20、「薄く」方向の段階詰め）

ユーザーの「この方向性でもう何パターンか作ってみて」で、同じ土台 P1GM1・同じ下瞼マスクで薄さの段階を3種追加した。

| | 内容 | 成果物 |
|---|---|---|
| L4 少し薄く（P1GM1とL2の中間狙い） | pattern_l4.png（SHA-256 d8c09e4d…） |
| L5 かなり薄く（L2より強い） | pattern_l5.png（SHA-256 5c14602c…） |
| L6 ほぼ消す（ライン除去） | pattern_l6.png（SHA-256 4b759e35…） |

- 検証：3種とも変更画素は約4.9〜5.0万 px で全て下瞼マスク内、マスク外差分ゼロ。
- 観察：薄くなる方向の大まかな流れは再現できたが、隣り合う段階の差は小さく、等間隔ではない。L5 と L6 は見た目が近く、L6 が最もラインが残っていない。生成の解釈のばらつきがあるため、厳密な段階というより候補の幅として見るのが適切。
- 比較シート：compare_lower_lid_gradation_face.png（顔全体）、compare_lower_lid_gradation_zoom.png（目元拡大）。並び順は P1GM1 → L4 → L2 → L5 → L6（薄さの狙い順）。
- ユーザー評価：2026-11-20、ユーザーは「イメージはL5」と判断。pattern_l5.png（かなり薄く）が作業版になり、下瞼は L2 から L5 へ差し替わった（TRIALのまま）。その上で追加の希望：現在のラインは上に凸のアーチなので、下に凸にしたい。ただしほぼ平行で、ほんの少しだけ下に凸という程度。

## ラウンド3（2026-11-20、L5のラインを下に凸へ・画素移動）

- 方法：生成ではなく画素の縦移動（非生成ワープ）。L5 の両目の下瞼帯で、ライン中央が最大・両端と上下でゼロになるコサイン減衰の変位場を使い、ライン中央だけを下へ移動した。強さ3段階（中央 3px／5px／8px）。
- 成果物：pattern_l5c1.png（3px、SHA-256 cd1f6b44…）、pattern_l5c2.png（5px、SHA-256 00e9b602…）、pattern_l5c3.png（8px、SHA-256 edf1815e…）。
- 検証：変更画素（約2.0〜2.3万 px）は全て変位場の範囲内のみ。それ以外は L5 と差分ゼロ。
- 観察：L5 のラインは非常に薄いため変化は繊細。中央を下げた分、下瞼の輪郭が少し平らに近づく。変位場は瞳下端の陰影にもわずかに及ぶが、肌の歪みなどの破綻は目視では確認できない。「ほぼ平行でちょっとだけ」という希望には C2（5px）が一番近い印象。
- 比較シート：compare_l5_curve_eyes.png（両目拡大）、compare_l5_curve_oneeye.png（片目大拡大）。実画像の非生成的配置。
- ユーザー評価：2026-11-20、「変化が小さすぎるからもっと強くしてほしい」。

## ラウンド4（2026-11-20、カーブ調整の強さ追加）

- 方法はラウンド3と同じ画素の縦移動。強さを中央 12px／16px／20px に上げた3種を追加。
- 成果物：pattern_l5c4.png（12px、SHA-256 864c5d01…）、pattern_l5c5.png（16px、SHA-256 00a1946b…）、pattern_l5c6.png（20px、SHA-256 588efebd…）。
- 検証：変更画素（約2.4〜2.5万 px）は全て変位場の範囲内のみ。それ以外は L5 と差分ゼロ。
- 観察：C4（12px）で下瞼の輪郭がはっきり平ら〜やや下に凸になり、自然な範囲で一番分かりやすい。C5（16px）は下がりが明確。C6（20px）は瞳の下端そのものが下へ引っ張られて見え、ラインだけでなく目の形の変化として目立ち始める（変位場が瞳下端の陰影にも及ぶため）。肌側の破綻はいずれも目視では確認できない。
- 比較シート：compare_l5_curve_strong_oneeye.png（片目大拡大）、compare_l5_curve_strong_eyes.png（両目拡大）。並びは L5 → C3 → C4 → C5 → C6。
- ユーザー評価：2026-11-21、強い variant まで全部見た上で、ユーザーは「C1がちょうど良さそう。このラインは今の所これでOK」と判断（当初は単に「C」と言い、確認後に C1 と訂正）。pattern_l5c1.png（L5＋中央3px下げ）が現在の作業版になった（TRIALのまま、正式採用ではない）。
- ユーザーの留保：変更履歴は残しておくこと。全体のバランスを見て、後からまた変えてもらうかもしれない — 下瞼ラインは暫定確定で、全体バランス確認後に再調整の可能性あり。C2〜C6・L1〜L6 の全 variant は履歴として保持し、いつでも差し替え可能。
- 現在の作業版の系譜：ヘアピンなし髪ベース（局所補修01試行01）→ 目P1 → 目の幾何拡大+6% → 口M1 → 下瞼L5（かなり薄く）→ カーブC1（中央3px下げ）。
