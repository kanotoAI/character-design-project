# Character Design Project

このリポジトリは、キャラクターデザイン制作における**唯一の正本（Source of Truth）**を管理します。

## 最重要ルール
1. 作業前に `rules/current_rules.md` を必ず確認する。
2. `planning/roadmap.md` と、対象キャラクターの `05_history/todo.md`・`manifest.md`・正本設定を確認する。
3. `MASTER` / `APPROVED_REFERENCE` だけを正式参照する。
4. `WORKING` / `TRIAL` は承認なしに正本扱いしない。
5. `REJECTED` は参照禁止。
6. ルールや正本を変更した方がよさそうな場合、無断変更せずユーザーへ相談する。
7. 部分修正では指定箇所以外を変更しない。変更不要部分は再生成しない。

## 構成
- `rules/`: プロジェクト共通の現行ルールと変更履歴
- `planning/roadmap.md`: 共通ToDo・今後の予定・保留事項
- `characters/<id>/`: キャラクター固有の正本・制作素材・履歴
- 各キャラクターの `05_history/manifest.md` が参照状態の入口
- 各キャラクターの `05_history/todo.md` が作業予定・後でやりたいことの記録先

## 作業予定と通知
- 「あとでやりたい」「覚えておいて」は、別途保存指示がなくても対応するToDoへ登録する。
- 実際に完了・検証した作業は、別途指示がなくてもToDoをDONEへ更新し、日付・結果を残す。
- ToDoは実行承認ではない。現在の作業段階・保留条件を確認し、次工程へ勝手に進まない。
- 日時指定の通知はChatGPTのリマインダー機能等で**別途設定が必要**。GitHubへの記録だけでは自動通知されない。
- 詳細は `rules/current_rules.md` 第20節。
