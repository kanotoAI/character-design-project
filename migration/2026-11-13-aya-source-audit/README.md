## 原本照合の原則
1. 元のファイルは削除せずローカルに保存。原文の内容変更を移管と混同しない。
2. GitHubには正本と試作を区別して登録。特に未確定の表情資料をAPPROVED_REFERENCE扱いしない。
3. 現行 `rules/current_rules.md` v2.5、玲奈の設定・承認状態は変更しない。
4. ChatGPTプロジェクトの差し替えは、GitHubへの実ファイル配置・照合を確認してから行う。
5. 画像バイナリと大きな原文の転送が未完了の場合は、完了したと報告しない。
