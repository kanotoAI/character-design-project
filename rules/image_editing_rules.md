# 画像編集・修正の運用ルール

更新日：2026-11-11  
基準：開始パック v1.0 の画像編集ルール

## 1. 基本方針
- 指定された修正箇所以外は変更しない。
- 元画像の構図・色彩・質感・細部を維持する。
- 修正指示を不必要に拡大解釈しない。
- 修正範囲が曖昧な場合は、勝手に広範囲を変更しない。
- 参照画像は指定された特徴の参照に限り、指定外の特徴を無断で移植しない。

## 2. 標準編集方法：部分合成方式
既存画像の修正では「部分合成方式」を標準とする。**画像全体の再生成を局所修正の完成画像として採用しない。**

### 2.1 変更範囲の定義
変更対象は次の2種類として定義する。
- **要素単位変更**：指定された要素だけを変更する。
- **領域単位変更**：指定されたパネル・枠・領域の内部全体を変更対象とする。

領域単位変更では、領域内は目的に応じて全面的に描き直し・再構成してよい。
ただし、**指定領域の外側は完全維持する。**
「変更しない部分」という指示は、原則として変更対象領域の外側を指す。

1. 原本と参照画像を区別し、修正対象を特定する。
2. 編集許可領域と編集禁止領域を明確にする。
3. 必要な場合だけ局所的な修正案を生成する。
4. 必要な修正部分だけを切り出す。
5. **原本を土台に**該当箇所だけを合成する。
6. 合成境界のみを必要最小限になじませる。
7. 修正範囲外の画素保持と修正範囲内の見た目を別々に検証する。

## 3. 完全維持
- 修正範囲と事前許可された境界調整範囲以外は元画像の画素を保持する。
- 指定されていない背景、人物、服装、構図、色味、質感、細部、文字を変更しない。
- 「ほかは変更しない」「完全維持」の場合、編集禁止領域の画素差分ゼロを必須条件とする。
- AI出力全体を完成画像として提出しない。
- 編集禁止領域に差分があれば不合格。
- 差分検証できない環境では完全維持を保証したと報告しない。
- 局所合成・差分検証を実行できない場合、無断で全体再生成に切り替えない。

## 4. 検証
### 画素
- 原本と完成画像のピクセル寸法が一致しているか。
- 編集禁止領域の画素差分がゼロか。透過画像はアルファも比較。
- 許可領域外に色調整、にじみ、輪郭変化がないか。
- 差分範囲と処理範囲が一致するか。

### 目視
- 修正対象が指示どおりか。
- 境界に欠け・浮き・重複・切断・継ぎ目がないか。
- 手指、手首、腕、足、輪郭、身体比率が自然か。
- 文字、数値、配色見本、装飾が意図せず変わっていないか。

画素差分ゼロと修正領域の自然さは別々の合格条件。

## 5. 出力
- 原則として元画像と同じピクセル寸法。
- 完成画像はPNGを基本とする。
- 原本を上書きせず、修正版を別ファイルとして保存。
- ファイル保存とプロジェクト登録は別工程。
- 実施していない工程を「完了」と報告しない。

## 6. 切り出し・透過・資料
- 元イラストを使えるなら再描画より直接切り出しを優先。
- 三面図等は縦横比を維持し、不必要な個別変形をしない。
- 手足、髪先、小物が切れない余白を確保。
- 透過で淡い輪郭が欠けるなら無理に完成扱いしない。
- 複数イラスト、文字、パレットを含む資料は各要素の編集可否を分ける。
- 拡大縮小、再描画、色変換した部分を「元画素完全維持」と報告しない。

## 7. 反復と不合格
- 明確な破綻がある候補を完成品として提出しない。
- 原則として指定原本からやり直し、劣化中間画像を無条件に次の原本にしない。
- 小領域の継ぎはぎで不自然になる場合、解剖学的に一体の修正範囲を相談する。
- 合格できない場合は無理に完成とせず、問題と代替案を示す。

## 8. 今後の運用
- ユーザーが毎回「部分合成方式」と指定する必要はない。
- より適切な方法が見つかった場合は、既存ルールを無断変更せず改訂案を提示する。
- 実行できない工程がある場合は完了を装わない。

## 9. 提出前チェック
- [ ] 原本と参照画像を正しく区別した
- [ ] 編集許可領域と編集禁止領域を特定した
- [ ] 編集禁止領域を生成結果で置換していない
- [ ] 完全維持指定なら画素差分ゼロを検証した
- [ ] 修正領域の自然さ、輪郭、接続、文字・配色を目視確認した
- [ ] 画像サイズ、形式、透過情報を確認した
- [ ] 実施工程、未検証事項、残る問題を正確に報告した

**最重要原則：変更を指示されていない画素は、生成AIに維持を期待するのではなく、原本から技術的に保持する。**
